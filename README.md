# Project 1: Triple Peaks Library

The Triple Peaks Library webpage is the first project in the Software Engineering
program at TripleTen. It was created using HTML and CSS, based on a design brief.

## Project features

- Semantic HTML5
- Flexbox
- Positioning
- Vertical stacking with z-index

## Technologies

- HTML
- CSS
- Normalize.css

## Running the project

Open `index.html` in a browser to view the page locally. No build step or package
installation is required.

## Project structure

- `index.html` — page markup
- `styles/style.css` — custom styles
- `images/` — images and icons used by the page
- `vendor/normalize.css` — browser style reset
